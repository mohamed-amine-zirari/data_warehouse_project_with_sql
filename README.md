# Data Warehouse and Analytics Project

Welcome to my **Data Warehouse and Analytics Project** 

This project is part of my learning journey in **Data Engineering**. I am building a modern data warehouse using **SQL Server**, focusing on data integration, ETL pipelines, data modeling, and analytics.

I also plan to integrate **SchemaSmith**, my Python-based CSV data cleaning and schema matching tool, into the data preparation stage. It will help standardize column names, handle missing values, detect anomalies, and prepare raw data for further processing.

Through this project, I aim to gain practical experience in building reliable data pipelines, transforming raw data into structured information, and generating meaningful insights to support data-driven decision-making.

This repository documents my implementation, experiments, and progress as I develop my data engineering skills.


## 🏗️ Data Architecture

The data architecture for this project follows Medallion Architecture **Bronze**, **Silver**, and **Gold** layers:

1. **Bronze Layer**: Stores raw data as-is from the source systems. Data is ingested from CSV Files into SQL Server Database.
2. **Silver Layer**: This layer includes data cleansing, standardization, and normalization processes to prepare data for analysis.
3. **Gold Layer**: Houses business-ready data modeled into a star schema required for reporting and analytics.
